# Urbautrix Bot

A maubot plugin that looks up a definition of a term in Urban Dictionary

<img width="50%" height="50%" alt="urbautrix" src="https://github.com/user-attachments/assets/58eb65e7-081a-4773-a147-91c6fa67e928" />

## Usage

Type the term you'd want to see explained
```
!urban <query>
```
